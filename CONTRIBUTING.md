# Contributing

Thanks for considering contributing to TVForge.

## Before opening a pull request

- Describe the Android TV device and Android version tested.
- Include reproducible steps for bugs.
- Keep features usable with a TV remote and D-pad.
- Avoid root requirements, firmware modifications, security bypasses, or destructive system changes.
- Do not submit proprietary APKs, copyrighted assets, or credentials.

## Development

Open the project in Android Studio with JDK 17 and Android SDK Platform 35. Build the `app` module and test on an Android TV emulator before testing physical devices.
