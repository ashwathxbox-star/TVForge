# Release checklist

- [ ] Build debug APK in Android Studio.
- [ ] Test on Android TV 11 emulator.
- [ ] Test D-pad focus and app launch.
- [ ] Test RAM/storage display.
- [ ] Test on at least one physical Android TV 11+ device.
- [ ] Verify default Home selection behavior.
- [ ] Capture screenshots from a real emulator/device.
- [ ] Build and sign a release APK with your own release key.
- [ ] Never commit keystores, passwords, or signing credentials.
- [ ] Publish source and APK checksums in GitHub Releases.
